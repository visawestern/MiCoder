◈ PROJECT REVIEW

MiMoMacOS

Нативное macOS-приложение для работы с AI-агентом MiMo. Функциональный клон интерфейса ZCode, построенный на SwiftUI. Подключается к локальному серверу MiMo Serve (HTTP API на порту 4096) и предоставляет полноценный чат-интерфейс с поддержкой сессий, воркспейсов и потоковой генерации ответов.

Замечания и рекомендации

# Категория Описание Приоритет
1 Архитектура SSEClient не имеет retry-логики — при обрыве соединения поток теряется Средний
2 Безопасность API-ключи кастомных провайдеров хранятся в UserDefaults (plaintext) Высокий
3 UX 5 вкладок Settings — UI-заглушки без функционала Низкий
4 Перформанс Нет кеширования моделей — каждый запуск загружает заново Низкий
5 Надёжность syncStart() метод создаёт фейковую сессию при ошибке — может запутать пользователя Средний
6 UX Нет индикатора подключения к серверу в реальном времени (только при загрузке) Низкий
7 Тестируемость Live-тесты依赖 от работающего сервера — нет моков для CI Средний
8 Архитектура MessageStore — in-memory only, сообщения теряются при перезапуске Высокий

MiMoMacOS — это работающий macOS-клиент для AI-агента MiMo. Приложение построено с чистой архитектурой, использует современные паттерны Swift (async/await, Codable, ObservableObject), и покрыто тестами.

Основные достижения: полная интеграция с MiMo Serve API, работающий SSE-стриминг, кастомная тема Dark/Sci-Fi Light, 81 тест, 10 шагов TDD для функциональной паритости с ZCode.

Следующие шаги: persistent storage для сообщений, retry для SSE, Keychain для API-ключей, доработка 5 заглушек в Settings, добавление анимаций и offline-режима.
