# Описание интерфейса ZCode — Скриншот 1_1

## Состояние: Открыт выпадающий список выбора рабочего пространства

На скриншоте отображается главное окно приложения ZCode с активным выпадающим меню выбора рабочего пространства (workspace). Пользователь нажал на селектор воркспейса в панели ввода, и теперь виден список доступных проектов для выбора.

---

## Левая боковая панель (Sidebar)

### Верхняя группа — основные действия

**Кнопка "New task" (⌘N)**
Расположена в самом верху левой боковой панели. Состоит из круглой иконки с символом плюса "⊕" и текстовой надписи "New task". Справа от текста отображается сочетание клавиш "⌘N" — стандартная горячая клавиша macOS для создания нового документа. При нажатии на эту кнопку в центральной области приложения создаётся全新 пустое поле ввода для начала нового диалога с AI-агентом. Рабочее пространство при этом остаётся тем же, что было выбрано ранее, но начинается новый контекст разговора без истории предыдущих сообщений. Это основная точка входа для начала работы в приложении — именно с этой кнопки начинается любой новый запрос к AI. Кнопка имеет тёмный фон, белый текст, при наведении может подсвечиваться.

**Кнопка "Search" (⌘K)**
Расположена сразу под кнопкой "New task". Состоит из иконки лупы "🔍" и текстовой надписи "Search". Справа отображается сочетание клавиш "⌘K" — быстрая команда поиска, которая вызывается нажатием на эту комбинацию клавиш в любой момент работы с приложением. При нажатии открывается поисковая панель или модальное окно поиска, которое позволяет искать по всем ранее созданным задачам, диалогам, файлам в рабочих пространствах и другому контенту. Поиск может работать по названию задачи, содержимому диалога или имени файла. Это мощный инструмент навигации для пользователей, у которых много задач и проектов — вместо того чтобы прокручивать весь список, можно быстро найти нужный элемент по запросу.

**Кнопка "Skills"**
Расположена сразу под кнопкой "Search". Состоит из иконки "✨" (блёстки/звёздочки, символизирующие магию или специальные возможности) и текстовой надписи "Skills". В отличие от предыдущих двух кнопок, здесь нет отображения сочетания клавиш — вызов этой функции доступен только через клик. При нажатии открывается раздел навыков (skills) — это специализированные расширения и плагины, которые расширяют возможности AI-агента. Например, навыки могут включать: генерацию изображений, работу с базами данных, деплой приложений, анализ кода, создание документации и многое другое. В верхней панели ввода также есть символ "$" для быстрого вызова навыков прямо из поля ввода, но эта кнопка открывает полноценный каталог доступных навыков с подробными описаниями и настройками каждого из них.

### Средняя группа — список рабочих пространств

**Заголовок секции "Workspaces" с иконкой раскрытия**
Расположена в средней части левой боковой панели, под основными кнопками. Текст "Workspaces" написан серым цветом较小ного размера — это заголовок секции, а не интерактивный элемент. Сразу справа от текста находится иконка "↗" (стрелка, направленная вверх-вправо) — кнопка раскрытия или перехода в расширенный режим управления рабочими пространствами. При нажатии эта иконка может: развернуть список всех воркспейсов на весь экран, открыть отдельное окно управления проектами, или переключить вид отображения списка. Сам заголовок "Workspaces" также может быть кликабельным для сворачивания/разворачивания секции со списком проектов.

**Иконка фильтра/сортировки (☰)**
Расположена справа от заголовка "Workspaces". Представляет собой три горизонтальные линии разных длин (иконка "гамбургера" или фильтра). При нажатии эта кнопка открывает меню сортировки или фильтрации рабочих пространств. Пользователь может: отсортировать воркспейсы по имени (А-Я или Я-А), по дате последнего использования, по количеству задач, по размеру проекта. Также может предоставить фильтры по статусу (активные, архивированные, избранные). Это полезный инструмент для пользователей с большим количеством проектов, который помогает быстро найти нужный воркспейс без прокрутки всего списка.

**Иконка поиска по воркспейсам (🔍)**
Расположена справа от иконки фильтра, в той же строке заголовка "Workspaces". Представляет собой маленькую иконку лупы. В отличие от глобального поиска (⌘K), который ищет по всему контенту приложения, эта кнопка предоставляет локальный поиск именно по рабочим пространствам. При нажатии в поле поиска (или открывается выпадающее поле) где можно ввести название воркспейса для быстрой фильтрации списка. Это удобно когда у пользователя десятки проектов и нужно быстро найти нужный по названию. Результаты фильтруются в реальном времени по мере набора текста.

**Иконка переключения вида (▦)**
Расположена справа от иконки поиска, завершает строку с иконками управления воркспейсами. Представляет собой сетку из четырёх квадратов (2×2) — стандартная иконка для переключения между видом "список" и видом "сетка/иконки". В текущем состоянии отображается вид "список" — рабочие пространства показаны вертикально с иконками папок и названиями. При нажатии на эту кнопку воркспейсы могут переключиться на вид "сетка", где каждый проект будет отображаться как карточка с превью, названием и кратким описанием.

**Рабочее пространство "tm3"**
Расположено в списке рабочих пространств сразу под заголовком "Workspaces". Состоит из иконки папки (📁) и текста "tm3" — названия проекта. Иконка папки стандартна для macOS и символизирует, что это директория на файловой системе. "tm3" — сокращённое название проекта, вероятно, это рабочее пространство, привязанное к папке "tm3" на диске пользователя. Это одно из доступных воркспейсов, между которыми можно переключаться. При нажатии на этот элемент выбирается данный воркспейс как основной контекст для новых задач.

**Подзадача "детально изучи каждую функ..." (метка "3d")**
Расположена в списке задач внутри рабочего пространства "tm3" — сразу под названием воркспейса. Текст обрезан (truncated) и отображается как "детально изучи каждую функ..." — это означает, что полное название задачи длиннее и не помещается в отведённое пространство сайдбара. Полное название, вероятно, звучит как "детально изучи каждую функцию [чего-то]" — это задача, которую пользователь ранее создал для AI-агента. Справа от текста отображается метка "3d" — это может означать: задаче 3 дня, статус "в работе 3 дня", третий день выполнения, или категория/приоритет. Задача кликабельна — при нажатии открывается полный диалог с историей взаимодействия по этой задаче.

**Рабочее пространство "ZCodeProject"**
Расположено в списке рабочих пространств под "tm3". Состоит из иконки папки и текста "ZCodeProject" — название второго проекта в списке. Это воркспейс, привязанный к проекту ZCode (возможно, к самому исходному коду приложения или связанному с ним проекту). Под названием отображается текст "No tasks yet" — это означает, что в данном рабочем пространстве пока не было создано ни одной задачи или диалога с AI. Пользователь может начать работу в этом воркспейсе, выбрав его и создав новую задачу.

**Текст "No tasks yet"**
Расположен под названием рабочего пространства "ZCodeProject". Представляет собой серый текст较小ного размера — это подсказка (placeholder) для пустого состояния. Информирует пользователя, что в выбранном воркспейсе пока нет созданных задач или диалогов с AI. Это стандартный паттерн UX для пустых списков — вместо пустого пространства показывается сообщение, объясняющее почему здесь пусто. Текст не кликабелен и не является интерактивным элементом. При создании первой задачи в этом воркспейсе текст исчезнет и появится название задачи.

### Нижняя группа — профиль и настройки

**Аватар пользователя "W"**
Расположен в самом низу левой боковой панели, в левом углу. Представляет собой круглый значок (аватар) оранжевого цвета с белой буквой "W" по центру. Буква "W" — первая буква имени пользователя "Win Pei", отображаемого справа. Оранжевый цвет可能是 случайно выбранным или заданным пользователем цветом профиля. Аватар является кликабельным элементом — при нажатии может открываться: меню профиля, настройки аккаунта,选项 выхода из системы, или переключения между пользователями. Размер аватара примерно 32×32 пикселя.

**Имя пользователя "Win Pei"**
Расположено справа от аватара "W" в самом низу левой боковой панели. Представляет собой текст "Win Pei" — имя текущего авторизованного пользователя. Текст написан белым или светлым цветом, хорошо читается на тёмном фоне сайдбара. Информирует пользователя о том, под каким аккаунтом он работает. Это может быть связано с облачным аккаунтом, локальным профилем или интеграцией с внешним сервисом (GitHub, Google и т.д.). Информация может быть кликабельной для перехода в настройки профиля, просмотра подписки, управления API-ключами или выхода из аккаунта.

**Иконка уведомлений (колокольчик)**
Расположена в правой части нижней строки левой боковой панели, между именем пользователя и иконкой настроек. Представляет собой стандартную иконку колокольчика (🔔), символизирующую уведомления. При нажатии открывается панель или выпадающий список уведомлений, которые могут включать: завершение задач AI, ответы на ранее отправленные запросы, системные оповещения (обновления, ошибки), упоминания или рекомендации. Если есть непрочитанные уведомления, на иконке может отображаться красная точка или число. Иконка серого цвета, компактная (примерно 18×18 пикселей).

**Иконка настроек (шестерёнка)**
Расположена в правом углу нижней строки левой боковой панели — самый правый элемент в сайдбаре. Представляет собой иконку шестерёнки (⚙️), стандартный символ настроек и конфигурации. При нажатии открывается окно или панель настроек приложения ZCode, которая может включать: выбор и настройка AI-моделей (API-ключи, эндпоинты), управление рабочими пространствами (создание, удаление, переименование), настройка темы оформления (светлая/тёмная тема), управление навыками и плагинами, настройка уведомлений, конфиденциальность и безопасность, информация о версии приложения.

## Центральная область — главное рабочее пространство

### Заголовок экрана

**Большой полупрозрачный логотип "Z"**
Расположен в центре основной рабочей области, занимая значительную часть экрана. Представляет собой крупную букву "Z" — логотип приложения ZCode, отображённую полупрозрачным серым цветом на тёмном фоне. Это декоративный элемент (watermark), который служит визуальным центром интерфейса в пустом состоянии (когда нет активного диалога). Логотип помогает пользователю понять, что он находится в главном экране приложения и может начать работу. Когда начинается диалог с AI, логотип исчезает и заменяется контентом разговора. Стиль минималистичный — геометрическая буква без дополнительных украшений, что соответствует общему дизайну приложения.

**Текст-призыв "...sk in ZCodeProject"**
Расположен под логотипом "Z" в центре основной рабочей области. Отображается текст较大ного размера, обрезанный справа из-за открытого выпадающего меню. Полный текст должен звучать как "Start a new task in ZCodeProject" — призыв к действию (call to action). Информирует пользователя, что он находится в рабочем пространстве "ZCodeProject" и может начать новую задачу. Текст белого цвета, хорошо читается на тёмном фоне. Является кликабельным — при нажатии, вероятно, фокус переключается на поле ввода внизу экрана. Название рабочего пространства dynamically подставляется из текущего выбранного воркспейса.

## Выпадающий список выбора рабочего пространства (АКТИВНЫЙ ЭЛЕМЕНТ)

Это главный активный элемент на данном скриншоте — пользователь нажал на селектор воркспейса в панели ввода, и теперь отображается выпадающий список с доступными опциями.

### Поле поиска "Search workspaces"
Расположено в верхней части выпадающего списка. Состоит из иконки лупы "🔍" и placeholder текста "Search workspaces". Это поле поиска, которое позволяет быстро найти нужный воркспейс по названию, не прокручивая весь список. При вводе текста список фильтруется в реальном времени, показывая только те воркспейсы, название которых содержит введённый запрос. Это удобно при большом количестве проектов. Поле активно и готово к вводу — при начале набора текста placeholder исчезает и появляется курсор.

### Элемент списка "tm3"
Расположен под полем поиска в выпадающем списке. Состоит из иконки папки и текста "tm3". Это первый доступный воркспейс в списке. Иконка папки стандартна для macOS и символизирует файловую директорию. Элемент кликабельный — при нажатии рабочее пространство "tm3" будет выбрано как активное, выпадающий список закроется, и в селекторе панели ввода отобразится "tm3". Также обновится текст-призыв в центральной области на "Start a new task in tm3".

### Элемент списка "ZCodeProject" (выбран, отмечен галочкой)
Расположен под элементом "tm3" в выпадающем списке. Состоит из иконки папки, текста "ZCodeProject" и значка галочки "✓" справа. Галочка указывает, что это текущее выбранное рабочее пространство — именно оно активно в данный момент. Это визуальная обратная связь для пользователя, показывающая какой воркспейс сейчас используется. При нажатии на этот элемент выпадающий список просто закроется (так как воркспейс уже выбран). Если пользователь выберет другой воркспейс, галочка переместится на него.

### Опция "Open folder"
Расположена под списком воркспейсов в выпадающем меню, отделена от списка визуальным разделителем (тонкая линия). Состоит из иконки папки с плюсом "⊞" и текста "Open folder". Это функция для добавления нового рабочего пространства путём выбора существующей папки на файловой системе. При нажатии открывается стандартный диалогFileChooser macOS, в котором пользователь может выбрать директорию на диске. Выбранная папка будет добавлена как новый воркспейс в список проектов. Это удобный способ подключить уже существующий проект для работы с AI.

### Опция "Remote connection"
Расположена в самом низу выпадающего списка. Состоит из иконки облака "☁" и текста "Remote connection". Это функция для подключения к удалённому серверу или репозиторию (например, SSH, Git remote, облачный storage). При нажатии открывается форма или диалог для ввода параметров подключения: адрес сервера, порт, учётные данные, тип протокола. Это позволяет работать с AI не только с локальными файлами, но и с удалёнными проектами — полезно для разработчиков, работающих с серверами или облачными инфраструктурами.

## Панель ввода (Input Bar)

### Верхняя строка — контекст задачи

**Селектор рабочего пространства "📁 ZCodeProject ▾"**
Расположен в левой части верхней строки панели ввода. Состоит из иконки папки, текста "ZCodeProject" и стрелки вниз "▾". Это интерактивный элемент, при нажатии на который открывается выпадающий список выбора воркспейса (именно этот список сейчас открыт на скриншоте). В данный момент отображается текущее выбранное рабочее пространство — "ZCodeProject". Стрелка "▾" визуально указывает на то, что это выпадающий список. После выбора воркспейса из выпадающего списка текст и иконка обновятся, и закрывающий значок "×" может появиться для быстрого сброса выбора. Это важный элемент, так как он определяет "где" будет работать AI-агент — к какому проекту привязан контекст задачи.

---

### Поле текстового ввода

**Основное поле ввода с placeholder текстом**
Расположено в центре панели ввода, занимает основную часть по ширине. Представляет собой прямоугольное поле с закруглёнными углами и тёмным фоном, отличающимся от фона приложения. Внутри отображается placeholder текст серым цветом: "Ask ZCode anything, @ to add files, / for commands, $ for skills, # related conversation". Это подсказка с синтаксисом специальных команд, доступных при вводе текста. Поле является основным интерактивным элементом — сюда пользователь вводит свои запросы к AI-агенту. При клике placeholder исчезает и появляется курсор. Поле поддерживает многострочный ввод для длинных запросов. Это сердце приложения — точка взаимодействия человека и AI.

**Подсказка с командами (@, /, $, #)**
Отображается внутри поля ввода как placeholder текст. Каждый символ является специальной командой: "@" — позволяет прикрепить файлы из рабочего пространства к запросу (аналог упоминания в соцсетях, но для файлов). "/" — вызывает меню slash-команд для быстрых действий (например, /clear для очистки контекста, /export для экспорта и т.д.). "$" — открывает каталог навыков (skills) для встраивания специализированных инструментов в запрос. "#" — позволяет привязать контекст из связанной беседы или другой задачи. Подсказка исчезает при начале ввода. Это элегантное решение для предоставления мощных возможностей без перегрузки интерфейса кнопками.

### Нижняя строка — настройки отправки

**Кнопка добавления вложений "+"**
Расположена в левой части нижней строки панели ввода. Представляет собой круглую кнопку с символом "+" (плюс). При нажатии открывается меню или диалог выбора вложений: файлы с диска, изображения, ссылки на документы, скриншоты или другой контекст, который пользователь хочет прикрепить к запросу. Это альтернативный способ добавления файлов (помимо использования "@" в тексте). Кнопка удобна для быстрого перетаскивания файлов или выбора нескольких вложений одновременно. После добавления вложений рядом с кнопкой может отображаться счётчик прикреплённых файлов.

**Выбор уровня доступа "✋ Ask before changes ▾"**
Расположена в нижней строке панели ввода, сразу справа от кнопки "+". Состоит из иконки руки "✋", текста "Ask before changes" и стрелки вниз "▾". Это выпадающий список для настройки уровня разрешений AI-агента к файловой системе и инструментам. "Ask before changes" означает, что агент будет спрашивать разрешение пользователя перед каждым изменением файлов — это безопасный режим, при котором пользователь контролирует все операции записи. Другие варианты могут включать: "Full access" (полный доступ — агент может свободно изменять файлы), "Read-only" (только чтение — агент не может изменять файлы), "Restricted" (ограниченный доступ — только безопасные операции). Иконка руки символизирует "остановку" или "проверку" перед действием. Это критически важный элемент для предотвращения случайных повреждений файлов.

**Выбор модели "🔵 GLM-5.2 ▾"**
Расположена в нижней строке панели ввода, справа от выбора доступа. Состоит из круглого индикатора (синий кружок), текста "GLM-5.2" и стрелки вниз "▾". Это выпадающий список для выбора языковой модели, которая будет генерировать ответы. "GLM-5.2" — текущая модель, вероятно, это большая языковая модель от Zhipu AI (GLM = General Language Model). Другие варианты могут включать: GPT-4, Claude, Gemini,或其他 специализированные модели. Выбор модели влияет на качество, скорость и стоимость ответов. Синий кружок可能是 индикатором статуса модели (активна/доступна). Это важный элемент для пользователей, которые хотят балансировать между качеством и скоростью.

**Выбор тира "⚡ Max ▾"**
Расположена в нижней строке панели ввода, справа от выбора модели. Состоит из иконки молнии (⚡), текста "Max" и стрелки вниз "▾". Это выпадающий список для выбора тира или уровня производительности модели. "Max" означает максимальное качество и производительность — модель будет использовать все доступные ресурсы для наилучшего результата. Другие варианты могут включать: "Standard" (стандартный баланс скорости и качества), "Fast" (быстрый режим — короткие ответы, меньше ресурсов), "Economy" (экономичный режим —最低 стоимость). Иконка молнии символизирует скорость и мощность. Выбор тира влияет на время отклика, качество ответов и, возможно, стоимость API-вызовов.

**Кнопка отправки "⬆️" (стрелка вверх)**
Расположена в правом углу нижней строки панели ввода — самый правый элемент во всей панели. Представляет собой круглую кнопку со стрелкой, направленной вверх (⬆️). Это кнопка отправки запроса — при нажатии весь введённый текст вместе с прикреплёнными вложениями и выбранным контекстом (воркспейс, агент, модель, тир, уровень доступа) отправляется AI-агенту для обработки. Кнопка может быть неактивной (серой), пока поле ввода пусто, и становится активной (подсвеченной) при вводе текста. Также запрос можно отправить нажатием Enter. После отправки в поле ввода появляется ответ AI, и интерфейс переключается в режим диалога.
